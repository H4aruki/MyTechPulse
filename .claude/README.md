# .claude/ — Claude Code の設定

このフォルダは、**このリポジトリで作業する全員に効く** Claude Code の設定を置く場所。各自の好みは対象外。

## ファイルの構成

```
.claude/
├── settings.json          … 許可と禁止、下記の仕掛けの登録（Git管理する）
├── settings.local.json    … 各自の好み（Git管理しない）
├── .cache/                … 仕掛けが使う作業ファイル（Git管理しない）
└── hooks/
    ├── guard-command.mjs  … 危険な操作を止める（コマンド実行の直前）
    ├── loop-guard.mjs     … 同じ操作の繰り返しを止める（同上）
    ├── format-edit.mjs    … 書き方を確認する（ファイル編集の直後）
    ├── mark-verified.mjs  … 編集と検査の実行を記録する（同上）
    ├── session-start.mjs  … 今の状況を読み込む（作業開始時）
    ├── verify-gate.mjs    … 検査せずに終わらせない（終了しようとしたとき）
    └── lib/               … 上記が共通で使う部品とそのテスト
```

## 動かすのに必要なもの

**Node 22 以上だけ。** 追加のライブラリは使っていない。自動チェックでも Node 22 を使っているので、画面側の組み立てができる環境ならそのまま動く。

書き方を整える道具（`ruff` / `oxlint`）と GitHub を操作する道具（`gh`）は、**見つかれば使い、無ければ黙って飛ばす。** 入っていなくても作業が止まることはない。`ruff` はどこからでも呼べる状態になっていないことが多いので、`backend/venv/` の中も順に探す作りにしてある。

## 何が起きるか

| いつ | 何が起きるか |
|---|---|
| コマンドを実行する直前 | 禁止事項に当たると実行されず、理由が返る。同じ操作が3回続いても止まる |
| ファイルを編集した直後 | 触ったファイル1つだけ書き方を確認する。自動修正はしない |
| 作業を始めたとき | 今の枝・変更の数・開いているプルリクエストと課題が自動で読み込まれる |
| 作業を終えようとしたとき | コードを編集したのに検査を一度も実行していなければ止まる |

### 検査せずに終わらせない仕掛けの考え方

止める条件は「コードを編集した後、検査を一度も実行していない」。毎回この条件を判定し直すので、**一度逃げ切れば以後は素通し、にはならない。**

条件が解除されるのは検査を**実行したとき**であって、**通ったとき**ではない。失敗しても抜けられるので止まらなくなる事故は起きず、そのうえで失敗した出力を見た状態になるので、正直な報告につながる。狙いはコードを緑にさせることではなく、実物の出力を見ずに完了と言わせないこと。

安全弁として、何の操作もせず終了だけを繰り返す完全な膠着状態になったときだけ3回目で通す。何か操作をすれば数え直しはゼロに戻るので、検査から逃げる抜け道にはならない。

## 禁止事項を変えるとき

**`AGENTS.md` の禁止事項と1対1で対応させてある。片方だけ変えないこと。**

- 止める対象そのもの: `hooks/lib/rules.mjs`（テストは `rules.test.mjs`）
- ファイル単位の禁止と、確認を求める対象: `settings.json` の `permissions`

変更したらテストを走らせる。

```bash
node --test ".claude/hooks/**/*.test.mjs"
```

## この仕掛けの限界（承知のうえで使うこと）

1. **繰り返しの検出は、まったく同じ操作しか捕まえられない。** 少しずつ違うコマンドで迷走するループは止まらない
2. **危険な操作の遮断は、よくある書き方を止めるもの。** 意図的な回避はできる。事故防止であって悪意への防御ではない
3. **検査せずに終わらせない仕掛けでできるのは、書き方と型と組み立ての確認まで。** 動作を確かめる自動テストがまだ無いため、「動作が正しいか」は確認できない

## 一時的に全部止めたいとき

各自の `.claude/settings.local.json` に次を書く（Git管理外なので他のメンバーには影響しない）。

```json
{ "disableAllHooks": true }
```
