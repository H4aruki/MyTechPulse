# 画面詳細: G-01 サービス紹介ページ（LP）

[画面一覧に戻る](../ScreenList.md) ／ 共通の取り決めは[画面に共通する決まりごと](../ScreenCommonRules.md)を参照

未登録・未ログインの人にサービスの内容を伝え、会員登録・ログインへ案内するための入口ページ。

| 項目 | 内容 |
| --- | --- |
| 実装場所 | `frontend/index.html` |
| ログイン | 不要 |
| 対応する機能 | F-1-1（サービス紹介ページの表示）、F-1-2（登録・ログインへの案内） |

## 1. このページだけの特徴

検索エンジンにインデックスさせ、SNS等でシェアされたときにOGPを効かせる必要があるため、Reactを読み込まない静的HTMLとして作っている。ログイン後のSPA（`/app/`配下）とは別実装。JavaScriptを一切使わないため、モバイルメニューの開閉もCSSの`:target`だけで実現している。

## 2. 構成

上から順に次のセクションが並ぶ、1ページ完結のLP。

| セクション | 内容 |
| --- | --- |
| ヘッダー | ロゴ、ページ内リンク（機能／仕組み／対応ソース）、新規登録・ログインへのボタン |
| ヒーロー | キャッチコピー、サービスの一言説明、新規登録・ログインへの導線 |
| パーソナライズの紹介 | タグ登録によってフィードが人それぞれ変わることの説明、記事カードのイメージ画像 |
| 課題提起 | 複数サイト巡回の手間・時間・情報の埋もれ、といった困りごとの列挙 |
| 機能一覧 | パーソナライズドフィード／複数サイト横断／最新記事の自動取得／学習時間の最適化、の4項目 |
| 使い方（3ステップ） | アカウント作成 → タグを選択 → フィードを受け取る |
| 対応ソース | Qiita・Zennへの外部リンク付きカード |
| CTA | 「今すぐ無料で始めてみよう」の再訴求と登録ボタン |
| フッター | サービス名・作成者のクレジット |

## 3. 表示項目

固定文言のみで、動的なデータ（記事・利用者情報など）は一切扱わない。パーソナライズ紹介セクションの記事カードもすべて固定のダミー表示。

## 4. 操作と遷移

| 操作 | 遷移先 |
| --- | --- |
| ヘッダー・ヒーロー・CTAの「無料アカウントを作成」等 | G-02 会員登録画面 |
| ヘッダー・ヒーローの「ログイン」 | G-03 ログイン画面 |
| ページ内リンク（機能／仕組み／対応ソース） | 同ページ内の該当セクションへスクロール |
| Qiita・Zennのロゴ／カード | 各サービスのサイトを新しいタブで開く |

## 5. レスポンシブの扱い

- `md`未満: ヘッダーのページ内リンクとボタンをハンバーガーメニューに収納する。パーソナライズ紹介・課題提起セクションは1カラム（縦積み）
- `md`以上: ヘッダーのページ内リンク・ボタンを横並びで常時表示。パーソナライズ紹介・課題提起セクションは2カラム
- 機能一覧カードは`sm`以上で2カラム、`sm`未満は1カラム
- 見出しの文字サイズは`sm`・`md`・`lg`で段階的に大きくする（スマホでの窮屈さとパソコンでの間延びの両方を避けるため）
- ヒーローのボタンはスマホ幅では横いっぱい、`sm`以上では文字幅に合わせる

## 6. 状態ごとの見え方

外部通信を行わないページのため、読み込み中・エラー・0件といった状態は無い。
