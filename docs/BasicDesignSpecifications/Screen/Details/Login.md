# 画面詳細: G-03 ログイン画面

[画面一覧に戻る](../ScreenList.md) ／ 共通の取り決めは[画面に共通する決まりごと](../ScreenCommonRules.md)を参照

利用者名・パスワードで本人確認を行い、記事一覧画面へ進むための画面。

| 項目 | 内容 |
| --- | --- |
| 実装場所 | `frontend/src/pages/LoginPage.tsx` |
| ログイン | 不要（ログインするための画面） |
| 呼び出す窓口 | A-2-2 ログイン（[Auth.md](../../API/Details/Auth.md)） |
| 対応する機能 | F-2-4（ログイン）、F-2-5（ログイン失敗時の表示）、F-2-6（本人確認）、F-2-7（保護された画面からの遷移先）、F-2-9（入力内容のチェック） |

## 1. 構成

| 表示項目 | 内容 |
| --- | --- |
| 見出し | 「ログイン」 |
| 入力欄 | ユーザー名、パスワード |
| ボタン | 「ログイン」 |
| 案内リンク | 「アカウントをお持ちでない方は 新規登録」→ G-02へ |

会員登録画面と違い、1ステップの単一フォームのみ。

## 2. 入力項目と入力チェック

| 項目 | 必須 | チェック内容 |
| --- | --- | --- |
| ユーザー名 | ○ | 未入力なら送信できず、欄の下にエラーを出す |
| パスワード | ○ | 同上 |

## 3. 状態ごとの見え方

| 状態 | 見た目 |
| --- | --- |
| 送信中 | 「ログイン」ボタンが押せなくなり、文言が「ログイン中…」に変わる |
| ログイン成功 | G-04（記事一覧）へ遷移する |
| ログイン失敗（利用者名不一致・パスワード不一致） | フォーム下部にエラーを表示する。「利用者名が存在しない」場合と「パスワードが違う」場合を区別せず、同じ表示にする（[画面共通の決まりごと](../ScreenCommonRules.md#5-エラー表示の見た目に関する決まり)の「送信結果のエラー」に従う） |

## 4. この画面への自動遷移

G-04（記事一覧）を、合言葉（JWT）を持たない状態で開こうとした場合、確認より先にこの画面へ自動的に戻される（F-2-7）。この場合、通常のログイン失敗とは異なりエラー表示は出さない。

## 5. レスポンシブの扱い

- フォームの最大幅を絞った1カラム表示。もともと構成要素が少ないため、スマホ・パソコンで大きなレイアウト変更は発生しない
- 入力欄・ボタンは画面幅いっぱいに広げ、スマホでのタップしやすさを確保する
