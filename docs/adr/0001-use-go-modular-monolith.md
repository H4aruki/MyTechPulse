# Go製モジュラーモノリスを採用する

2026-09-14、堅牢性・保守性・運用の単純さ・将来のチーム開発を両立するため、PythonバックエンドをGo製のモジュラーモノリスへ段階移行すると決めた。現行レイヤーの直訳は責務集中を残し、マイクロサービスは現在の規模に対して運用負担が大きいため採用しない。Go版は1つの配布単位を保ち、認証、記事、興味プロファイル、推薦、外部メディアを内部境界で分ける。

既存利用者データを守るため、Go版は `server/` へ並行構築し、既存PostgreSQLのテーブル名と列名を切り戻し期間中は維持する。Python版は本番安定確認まで残し、削除には別途許可を必要とする。
