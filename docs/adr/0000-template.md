# 題名（何を決めたかが分かる名詞句）

- 状態: 提案 / 採用 / 置き換え（→ 番号）。上の `status:`（`proposed` / `accepted` / `superseded`）と同じ値にする。一部だけ未確定なら、未確定の部分を本文に書く
- 日付: YYYY-MM-DD（決めた日。追加・変更したら行を足す）
- 決定者: 人の名前。AIは起案者として書く

意思決定ログは最も重要な成果物の一つです。下の9項目は、**すべて必ず書きます**。短いADRでも項目は減らしません。当てはまらない項目は、空欄にせず「なし」と理由を1行書きます。

## 根拠のデータ・事実

- 数値、確認したコマンドやAPI、確認した日時（JST）。あとから同じことを確かめられる書き方にする。

## 結果と代償

- 良くなること、引き換えに失うもの（トレードオフ）、残るリスクと対策。

## 見直し方
