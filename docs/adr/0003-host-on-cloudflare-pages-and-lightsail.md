# 画面をCloudflare Pages、API・DBをAWS Lightsail 1台に置く

2026-08-13（#64〜#67）、画面（静的なページとReactの画面）を Cloudflare Pages、API・DB・HTTPS化のCaddyを AWS Lightsail の1台（東京・1GB・約$7/月）に同居させる2分割構成に決めた。合計は月約$8。2026-10-07 にAPIをGo版へ切り替えた後も、この構成のまま。

**DBを3つ目の置き場に分けない理由**: テーブルは3つで書き込みも少なく、マネージドDBは要件に対して過剰で月$8〜25かかり予算を超える。1回の画面表示でDBへ複数回問い合わせるため、外に出すと往復の遅延が積み上がる。

**却下した候補**:
- Vercel: 無料プランが非商用に限られる。
- GitHub Pages: 接続先URLの書き換えができない。
- Netlify: 転送量に上限がある。
- Xserver VPS: 年契約で、後から変えにくい。
- EC2: 通信費が従量課金。
- GCP の無料VM: リージョンが米国のみ。
- Oracle の無料VM: アカウントを作成できなかった。

**次点**: さくらのVPS。Lightsailが合わなくなったときの第一候補。

**運用上の前提**: Lightsail 1GB はメモリが小さいため、スワップ2GBを作り、`vm.swappiness=10` にしている。実測では、起動直後の使用量はメモリの約半分で、当面は2GBプランへ上げる必要はない。バックアップは、いまは同じサーバーに保存しているため、外部への退避が残っている（`TASKS.md`）。
