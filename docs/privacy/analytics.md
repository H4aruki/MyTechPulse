# プライバシーポリシーに入れる「分析ツール」の節（案）

この文書は案です。プライバシーポリシーのページは、まだありません（[Issue #185](https://github.com/H4aruki/MyTechPulse/issues/185)）。
ページを作るときに、この節を取り込みます。本文は、オーナーの承認を得てから公開します。

## 利用状況の分析について

MyTechPulse は、画面を使いやすくするために、分析ツール PostHog（米国リージョン）を使います。

### 集める情報

- 見たページ（画面を移動した記録を含みます）
- クリックなどの操作
- 画面上の操作の記録（セッションリプレイ）。操作の流れを、あとから再生して確認するためのものです

### 集めない情報

- 入力欄に入れた内容は、すべて伏せて記録します。パスワードも記録しません
- メールアドレス、氏名、利用者名は送りません。利用者を見分けるには、サービスの内部で使う利用者の番号だけを使います。この番号から、名前や連絡先は分かりません
- 利用者名など、個人を特定できる表示は、クリックの記録と画面の記録の文字から外します
- ログアウトすると、その利用者との結び付きを外します

### 送らない場合

分析ツールの設定が入っていない環境（開発中の環境など）では、分析ツールを読み込まず、情報を一切送りません。

## 実装との対応

| 文面 | 実装 |
| --- | --- |
| 入力欄を伏せる | `frontend/src/lib/analytics.ts` の `session_recording.maskAllInputs` |
| 利用者名を外す | `ph-no-capture` クラス（`MyPage.tsx`、`SettingsPage.tsx`） |
| 内部の番号だけで識別する | `identifyUser`（`/auth/me` の `id`） |
| ログアウトで結び付きを外す | `resetOnSessionEnd` |
| 設定がなければ送らない | 環境変数 `VITE_POSTHOG_KEY`、`VITE_POSTHOG_HOST`（どちらかが空なら無効） |
